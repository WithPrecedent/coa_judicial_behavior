    2. coa_judicial_behavior

    Ideology, activism, partisanship, and independence of appellate judges.

    The scores follow the methods of Corey Rayburn Yung's studies of the judges of the federal courts of appeals (see coa_judicial_behavior.scores), from opinions that courtpy collects from CourtListener and codes. Importing the package adds its techniques to the amos library, so a study's settings can name them: code_review, code_district_judge, review_votes, score_judges, and validate_scores.

    Contents

    CodeDistrictJudge: finds the district judge whose judgment each case reviews. CodeReview: sorts each case by its standard of review. PREDICTORS: the variables for control and prediction that the scores add to the votes. Project: amos.Project (which courtpy offers under the same name), which loads and analyzes the cases that a settings file describes. ReviewVotes: makes the table of votes, with each vote's super-panel. RULEBOOK: the path of the rules that find what the scores need in each opinion. ScoreJudges: scores the judges and adds the predictors to the votes. Typology: the judging styles of the judges. ValidateScores: repeats the studies' tests of the scores. add_predictors: adds the scores to a table of votes. classify: sorts judges into judging styles. score_judges: returns the four scores of every judge. validate: returns the studies' tests of the scores.

    CodeDistrictJudge() dataclass ¶

    Bases: Munger

    Finds the district judge whose judgment each case reviews.

    Each name in "district_judges" (which "instructions/review.csv" finds in the lines about the court appealed from) is matched to a judge in a roster (see courtpy.judges.Roster), among the district judges of the case's circuit who were serving in its year. The first name that fits one judge is the district judge. A judge who also sat on the panel (as a district judge sitting by designation does) is not taken for the district judge. Adds:

    Column Meaning
    district_judge The district judge's name, as the roster reports it.
    district_judge_nid The Federal Judicial Center's number for the judge.
    district_party The party of the president who appointed the judge: -1 for a Democrat and 1 for a Republican.
    district_{attribute} Each other attribute named in attributes (such as district_jcs, the judge's Judicial Common Space score).

    Needs "district_judges", "court_num", and "year".

    def munge(
    self,
    data: pd.DataFrame,
    roster: judges.Roster | pd.DataFrame | pathlib.Path | str | None = (
        None),
    column: str = 'district_judges',
    attributes: Sequence[str] | str | None = None,
    **kwargs: Any) -> pd.DataFrame:
    """Adds the district judge of each case.

    Args:
        data: the parsed cases.
        roster: a roster, the table of one, or the path of a saved one.
            Defaults to `None`, in which case the roster saved in
            "judges" in courtpy's data folder is used.
        column: name of the column with the names of the district judge.
            Defaults to "district_judges".
        attributes: names of the roster's columns to add, other than
            "party". Defaults to `None`, in which case "jcs" is added if
            the roster has it.
        **kwargs: not used.

    Raises:
        KeyError: if the cases lack a column that is needed.

    Returns:
        The cases, with the new columns.

    """
    missing = [
        c for c in (column, 'court_num', 'year') if c not in data.columns]
    if missing:
        message = f'{self.name!r} needs the columns {missing}'
        raise KeyError(message)
    found = judges.Roster.create(roster)
    table = found.data
    if attributes is None:
        attributes = ['jcs'] if 'jcs' in table.columns else []
    wanted = ['party', *[
        a for a in _listify(attributes) if a in table.columns]]
    district = table[table['court_type'] == _DISTRICT_COURT]
    circuits = {
        int(float(str(number))): judges.Roster(rows, grace = found.grace)
        for number, rows in district.groupby('circuit_num')}
    panels = _panel_nids(data)
    rows: list[dict[str, Any]] = []
    for names, court, year, panel in zip(
        data[column], data['court_num'], data['year'], panels,
        strict = True):
        rows.append(_district_judge(
            _names(names), circuits.get(_whole(court) or -1),
            _whole(year), panel, wanted))
    added = pd.DataFrame(rows, index = data.index)
    data['district_judge'] = added['district_judge'].astype(object)
    data['district_judge_nid'] = added['district_judge_nid'].astype(
        'Int64')
    for name in wanted:
        data[f'district_{name}'] = added[name].astype('float64')
    return data

    CodeReview() dataclass ¶

    Bases: Munger

    Sorts each case by its standard of review.

    Standards of review are the formal rules that tell an appellate court how much to defer to the court below, and the activism, partisanship, and ideology scores all compare what judges do under deferential and nondeferential standards. A case is "deferential" if the opinion names only deferential standards (clear error, abuse of discretion, arbitrary and capricious, substantial evidence, or plain error), "non_deferential" if it names only de novo review, and "unclear" if it names both or neither, which is how the studies sorted them. Adds:

    Column Meaning
    review_standard "deferential", "non_deferential", or "unclear".
    review_deferential, review_de_novo Whether the standard is deferential, or de novo.
    review_has_standard Whether the opinion names any standard of review (or uses words that announce one), as every case in the studies did.
    review_excluded Whether the case is one that the studies left out: habeas corpus or immigration.
    review_of_district Whether the case reviews a district court: the appeal came from one (or its judge was found), and it is not a petition to review an agency.

    Needs the standard_... flags. Uses the columns that "instructions/review.csv" makes, and the habeas and immigration flags of courtpy's civil rules, if they exist.

    def munge(
    self,
    data: pd.DataFrame,
    deferential: Sequence[str] | str | None = None,
    non_deferential: Sequence[str] | str | None = None,
    excluded: Sequence[str] | str | None = None,
    **kwargs: Any) -> pd.DataFrame:
    """Sorts each case by its standard of review.

    Args:
        data: the parsed cases.
        deferential: names of the flags of deferential standards.
            Defaults to `None`, in which case they are `DEFERENTIAL`.
        non_deferential: names of the flags of nondeferential standards.
            Defaults to `None`, in which case they are `NON_DEFERENTIAL`.
        excluded: names of the flags of the cases to leave out. Defaults
            to `None`, in which case they are habeas corpus and
            immigration.
        **kwargs: not used.

    Raises:
        KeyError: if the cases have none of the flags of either kind of
            standard.

    Returns:
        The cases, with the new columns.

    """
    deferring = _any(data, _listify(deferential) or DEFERENTIAL)
    novo = _any(data, _listify(non_deferential) or NON_DEFERENTIAL)
    if deferring is None or novo is None:
        message = (
            f'{self.name!r} needs the flags of the standards of review '
            f'(such as "standard_de_novo"), which the federal rules of '
            f'courtpy make'
        )
        raise KeyError(message)
    standard = np.select(
        [deferring & ~novo, novo & ~deferring],
        ['deferential', 'non_deferential'], default = 'unclear')
    data['review_standard'] = pd.Series(
        standard, index = data.index, dtype = object)
    data['review_deferential'] = data['review_standard'] == 'deferential'
    data['review_de_novo'] = data['review_standard'] == 'non_deferential'
    named = _any(data, ['standard_named'])
    data['review_has_standard'] = (
        deferring | novo | (False if named is None else named))
    left_out = _any(data, _listify(excluded) or _EXCLUDED)
    data['review_excluded'] = (
        pd.Series(False, index = data.index) if left_out is None
        else left_out)
    district = _any(data, ['review_district'])
    agency = _any(data, ['review_agency'])
    found = (
        data['district_judge_nid'].notna()
        if 'district_judge_nid' in data.columns else False)
    data['review_of_district'] = (
        (pd.Series(False, index = data.index) if district is None
         else district) | found) & ~(
            False if agency is None else agency)
    return data

    Makes the table of votes, with one row for each judge on each case.

    The table is courtpy's table of votes (see courtpy.judges.vote_table) with the super-panel of each vote added (see describe_panels). It replaces the table of cases, so it comes after the techniques that code the cases and, like every shaper, before the data is split. Its "case_id" column should be the "groups" of a study, which keeps the judges of a case together.

    def apply(
    self,
    item: amos.Dataset,
    *,
    train: str | None = None,
    method: str = 'typology',
    minimum: int = 200,
    cell_minimum: int = 5,
    provoked: str = 'author',
    circuit: str | None = None,
    log_offset: float = 0.01,
    by: str | None = None,
    clusters: int = 9,
    styles: bool = True,
    merge: bool = True,
    **kwargs: Any) -> amos.Dataset:
    """Scores the judges of the votes in `item`.

    Args:
        item: the dataset of votes (as `review_votes` makes it).
        train: a query that selects the votes to score from. Defaults to
            `None`, in which case every vote is used.
        method: "typology" or "original". Defaults to "typology".
        minimum: fewest interactions for a judge to define the scales.
            Defaults to 200.
        cell_minimum: fewest votes in a cell for a judge's own rate.
            Defaults to 5.
        provoked: "author" or "panel". Defaults to "author".
        circuit: the circuit adjustment, or `None` for each score's own
            under `method`. Defaults to `None`.
        log_offset: what is added before the logarithm of the raw
            Independence Scores. Defaults to 0.01.
        by: name of a column whose values are scored separately.
            Defaults to `None`.
        clusters: the number of judging styles. Defaults to 9.
        styles: whether to sort the judges into styles. Defaults to
            `True`.
        merge: whether to add the predictors to the votes. Defaults to
            `True`.
        **kwargs: not used.

    Returns:
        The dataset, with the tables of scores and styles and, with
            `merge`, the predictors.

    """
    data = item.data
    mask = _selected(data, train)
    table = scoring.score_judges(
        data[mask], method = method, minimum = int(minimum),
        cell_minimum = int(cell_minimum), provoked = provoked,
        circuit = circuit, log_offset = float(log_offset), by = by)
    made = [self.name]
    if _flag(styles):
        table = _classify(table, int(clusters), by, item, made)
    item.tables[self.name] = table
    created: list[str] = []
    if _flag(merge):
        added = add_predictors(data, table, by = by, train = mask)
        added['holdout'] = ~mask.to_numpy()
        created = [c for c in added.columns if c not in data.columns]
        item.replace(added)
    item.record(
        self.name, tables = made, created = created,
        judges = len(table),
        qualified = int(table['qualified'].sum()),
        scored_votes = int(mask.sum()))
    return item

    ValidateScores() dataclass ¶

    Bases: Describer

    Repeats the studies' tests of the scores.

    Each test is a probit regression of an outcome on one measure at a time, with standard errors clustered by case, among the votes left out of the scores (see score_judges). The table has a row for each test and measure (see validate). A measure that a study's score was meant to improve on (the party of the appointing president, the Judicial Common Space score) is tested beside it, so their pseudo-R-squared values can be compared, as the studies compared them.

    def add_predictors(
    votes: pd.DataFrame,
    scores: pd.DataFrame,
    *,
    by: str | None = None,
    train: pd.Series | None = None) -> pd.DataFrame:
    """Adds the judges' scores and the variables made from them to the votes.

    Args:
        votes: a table of votes (see `review_votes`).
        scores: the table of scores (see `score_judges`), with "style" if the
            judges were sorted into styles.
        by: name of the column that the judges were scored separately by, if
            they were. Defaults to `None`.
        train: whether each vote was one that the scores were computed from,
            for "expected_reversal". Defaults to `None`, in which case every
            vote was.

    Returns:
        The votes, with the variables of `PREDICTORS` (except "holdout").

    """
    keys = ['judge_nid', *([by] if by else [])]
    columns = {
        score: f'judge_{score}' for score in _SCORES if score in scores}
    if 'style' in scores.columns:
        columns['style'] = 'judge_style'
    columns['qualified'] = 'judge_scored'
    judged = scores[[*keys, 'circuit', *columns]].rename(columns = columns)
    circuit = (
        judged[judged['judge_scored']]
        .groupby([*([by] if by else []), 'circuit'])['judge_ideology'].mean()
        .rename('circuit_ideology').reset_index())
    judged = judged.merge(circuit, on = [*([by] if by else []), 'circuit'],
                          how = 'left').drop(columns = 'circuit')
    table = votes.drop(
        columns = [c for c in judged.columns if c in votes.columns
                   and c not in keys] + [
            c for c in PREDICTORS if c in votes.columns and c != 'holdout'])
    numbers = pd.to_numeric(table['judge_nid'], errors = 'coerce')
    left = table.assign(judge_nid = numbers.astype('Int64'))
    judged = judged.assign(
        judge_nid = pd.to_numeric(judged['judge_nid']).astype('Int64'))
    merged = left.reset_index().merge(judged, on = keys, how = 'left')
    merged = merged.set_index(votes.index.name or 'index')
    merged.index.name = votes.index.name
    merged['judge_nid'] = votes['judge_nid'].to_numpy()
    merged['judge_scored'] = merged['judge_scored'].fillna(False).astype(bool)
    cases = merged['case_id']
    for score in _SCORES:
        column = f'judge_{score}'
        if column not in merged.columns:
            continue
        values = merged[column].astype('float64')
        total = values.groupby(cases).transform('sum')
        count = values.groupby(cases).transform('count')
        others = count - values.notna()
        merged[f'colleagues_{score}'] = (
            (total - values.fillna(0)) / others).where(others > 0)
    ideology = merged['judge_ideology'].astype('float64')
    merged['panel_ideology_median'] = ideology.groupby(cases).transform(
        'median')
    merged['panel_ideology_net'] = ideology.groupby(cases).transform(
        lambda v: v.sum(min_count = 1))
    for score in ('activism', 'partisanship', 'independence'):
        merged[f'panel_{score}_mean'] = merged[f'judge_{score}'].astype(
            'float64').groupby(cases).transform('mean')
    merged['panel_independence_max'] = merged['judge_independence'].astype(
        'float64').groupby(cases).transform('max')
    merged['ideological_distance'] = (
        ideology - merged['colleagues_ideology']).abs()
    merged['circuit_deviation'] = (ideology - merged['circuit_ideology']).abs()
    district = (
        pd.to_numeric(merged['district_party'], errors = 'coerce')
        if 'district_party' in merged.columns
        else pd.Series(np.nan, index = merged.index))
    merged['ideological_pressure'] = ideology / 100 * -district
    opposed = merged.get('district_opposed')
    side = (
        pd.Series(np.nan, index = merged.index) if opposed is None
        else pd.Series(np.where(
            opposed.astype('boolean').fillna(False), 1.0, -1.0),
            index = merged.index).where(opposed.notna()))
    merged['partisan_pressure'] = (
        (merged['judge_partisanship'] - 50) / 50 * side)
    deferential = (
        merged['review_deferential'].astype('boolean').fillna(False)
        if 'review_deferential' in merged.columns
        else merged['review_standard'] == 'deferential')
    merged['activist_pressure'] = (
        (merged['judge_activism'] - 50) / 50 * deferential.astype(float))
    merged['expected_reversal'] = _expected_reversal(merged, train)
    merged['concurred_only'] = (
        merged['judge_concurred'].astype('boolean').fillna(False)
        & ~merged['judge_dissented'].astype('boolean').fillna(False)).astype(
            bool)
    return merged

    def classify(
    scores: pd.DataFrame,
    clusters: int = 9,
    *,
    names: Sequence[str] | None = None,
    only_qualified: bool = True) -> Typology:
    """Sorts judges into styles by Ward's cluster analysis.

    Args:
        scores: the table of scores (see `score_judges`), with "ideology",
            "activism", "partisanship", and "independence" (and "qualified",
            if `only_qualified`).
        clusters: the number of clusters. Defaults to 9, as in the article.
        names: the names of the styles to match the clusters to. Defaults to
            `None`, in which case they are `STYLES` if `clusters` is 9, and
            else the clusters are named by their numbers.
        only_qualified: whether to classify only the judges who define the
            scales of the scores. Defaults to `True`.

    Raises:
        ValueError: if there are fewer judges to classify than clusters.

    Returns:
        The styles of the judges.

    """
    features = pd.DataFrame({
        'ideological': scores['ideology'].abs(),
        'activism': scores['activism'],
        'partisanship': scores['partisanship'],
        'independence': scores['independence']}, index = scores.index)
    keep = features.notna().all(axis = 1)
    if only_qualified and 'qualified' in scores.columns:
        keep &= scores['qualified'].astype(bool)
    features = features[keep]
    if len(features) < max(clusters, 2):
        message = (
            f'{len(features)} judges cannot be sorted into {clusters} '
            f'clusters')
        raise ValueError(message)
    tree = hierarchy.linkage(features.to_numpy(dtype = 'float64'), 'ward')
    found = hierarchy.fcluster(tree, t = clusters, criterion = 'maxclust')
    # The clusters are numbered in the order that their judges first appear
    # among the leaves of the tree.
    leaves = hierarchy.leaves_list(tree)
    order: dict[int, int] = {}
    for leaf in leaves:
        order.setdefault(int(found[leaf]), len(order) + 1)
    numbered = pd.Series(
        [order[int(c)] for c in found], index = features.index,
        name = 'cluster')
    means = features.groupby(numbered).mean()
    spread = features.std(ddof = 1).replace(0, np.nan)
    standardized = (means - features.mean()) / spread
    labels, distance = _name(
        standardized, list(names) if names is not None else (
            list(STYLES) if len(means) == len(STYLES) else None))
    profiles = pd.concat([
        pd.DataFrame({
            'style': labels, 'judges': numbered.value_counts().sort_index()}),
        means,
        standardized.add_suffix('_z'),
        pd.DataFrame({'distance': distance})], axis = 1)
    profiles.index.name = 'cluster'
    gaps = means.to_numpy()[:, None, :] - means.to_numpy()[None, :, :]
    counts = (np.abs(gaps) >= spread.to_numpy()).sum(axis = 2)
    differences = pd.DataFrame(counts, index = means.index, columns = means.index)
    assignments = pd.DataFrame({
        'cluster': numbered, 'style': numbered.map(labels)})
    return Typology(
        assignments = assignments, profiles = profiles,
        differences = differences)

            partisanship: "per_judge", "per_vote", "full", or "none".

            before their logarithm is taken, so that the lowest is not zero.
            Defaults to 0.01 (one percentage point).
        by: name of a column (such as "year") whose values are scored

        ValueError: if `method`, `provoked`, or `circuit` is not one of its

    _check(method, METHODS, 'method')
    _check(provoked, _PROVOKED, 'provoked')
    if circuit is not None:
        _check(circuit, _CIRCUIT_METHODS, 'circuit')

    def score(frame: pd.DataFrame) -> pd.DataFrame:
        return _score(
            frame, method = method, minimum = int(minimum),
            cell_minimum = int(cell_minimum), provoked = provoked,
            circuit = circuit, log_offset = float(log_offset))

    if by is None:
        return score(votes)
    tables = []
    for value, group in votes.groupby(by, sort = True):
        table = score(group)
        table.insert(1, by, value)
        tables.append(table)
    return pd.concat(tables, ignore_index = True)

    def validate(
    votes: pd.DataFrame,
    *,
    holdout_only: bool = True,
    tests: Sequence[str] | None = None) -> pd.DataFrame:
    """Returns the studies' tests of the scores.

    | Test | Rows | Outcome | Measures |
    | --- | --- | --- | --- |
    | `civil_rights` | Cases under Title VII, section 1983, or the ADA whose plaintiff won or lost (2010) | `outcome_civil_plaintiff_won` | The panel's median and net Ideology Scores, its median Judicial Common Space score, and the mean party of its appointing presidents. |
    | `dissent` | Every vote (2012) | `judge_dissented` | The Independence Score, the absolute Ideology Score, and the absolute Judicial Common Space score. |
    | `concurrence` | Every vote (2012) | `concurred_only` | The same. |
    | `partisan_reversal` | Votes under a deferential standard with a district judge of known party (2012) | `vote_reversal` | `partisan_pressure`, `ideological_pressure`, and whether the district judge is of the other party. |
    | `activist_reversal` | Votes under a deferential standard (2011) | `vote_reversal` | The Activism Score. |

    Args:
        votes: the votes, with the predictors (see `add_predictors`).
        holdout_only: whether to test only the votes left out of the scores
            (if "holdout" is a column). Defaults to `True`.
        tests: names of the tests to run. Defaults to `None`, in which case
            every test whose columns exist is run.

    Returns:
        A table with a row for each test and measure: "test", "measure",
            "coefficient", "std_error", "z", "p_value", "pseudo_r2"
            (McFadden's), and "observations". A measure that could not be
            fitted (too few rows or no variation) has missing values.

    """
    data = votes
    if holdout_only and 'holdout' in data.columns and data['holdout'].any():
        data = data[data['holdout'].astype(bool)]
    deferential = (
        data['review_standard'] == 'deferential'
        if 'review_standard' in data.columns
        else pd.Series(False, index = data.index))
    data = data.assign(
        abs_jcs = pd.to_numeric(data['judge_jcs'], errors = 'coerce').abs()
        if 'judge_jcs' in data.columns else np.nan,
        district_other_party = pd.to_numeric(
            data['district_opposed'].astype('Float64'), errors = 'coerce')
        if 'district_opposed' in data.columns else np.nan)
    plans: dict[str, tuple[pd.DataFrame, str, list[str]]] = {}
    present = [c for c in _CIVIL_RIGHTS if c in data.columns]
    if present and 'outcome_civil_plaintiff_won' in data.columns:
        civil = data[data[present].fillna(False).astype(bool).any(axis = 1)]
        if 'judge_jcs' in civil.columns:
            civil = civil.assign(panel_jcs_median = pd.to_numeric(
                civil['judge_jcs'], errors = 'coerce').groupby(
                    civil['case_id']).transform('median'))
        civil = civil.drop_duplicates('case_id')
        plans['civil_rights'] = (
            civil, 'outcome_civil_plaintiff_won',
            ['panel_ideology_median', 'panel_ideology_net',
             'panel_jcs_median', 'panel_party'])
    plans['dissent'] = (
        data, 'judge_dissented',
        ['judge_independence', 'judge_ideological', 'abs_jcs'])
    plans['concurrence'] = (
        data, 'concurred_only',
        ['judge_independence', 'judge_ideological', 'abs_jcs'])
    plans['partisan_reversal'] = (
        data[deferential & data['district_other_party'].notna()],
        'vote_reversal',
        ['partisan_pressure', 'ideological_pressure', 'district_other_party'])
    plans['activist_reversal'] = (
        data[deferential], 'vote_reversal', ['judge_activism'])
    rows = []
    for test, (rows_of, outcome, measures) in plans.items():
        if tests is not None and test not in tests:
            continue
        if outcome not in rows_of.columns:
            continue
        for measure in measures:
            if measure not in rows_of.columns:
                continue
            rows.append({
                'test': test, 'measure': measure,
                **_probit(rows_of, outcome, measure)})
    return pd.DataFrame(rows, columns = [
        'test', 'measure', 'coefficient', 'std_error', 'z', 'p_value',
        'pseudo_r2', 'observations'])
